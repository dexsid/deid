# Deid

Локальная авторская платформа на Next.js App Router, TypeScript и CSS Modules.

## Запуск

Нужен Node.js 22 и npm. Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Сервер слушает только loopback.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты сами запускают production-сервер на 127.0.0.1:3100, поэтому сначала нужна сборка. Vitest проверяет SQLite в отдельных временных каталогах и закрывает соединения после тестов. Не используйте рабочую БД в тестах.

`openDatabase(path)` из `lib/db.ts` применяет SQL-миграции транзакционно и возвращает соединение SQLite, Drizzle и `close()`. Каталог для БД должен существовать. Запускайте из корня проекта: миграции читаются из `migrations/`. При будущей standalone-упаковке SQL-файлы нужно включить в артефакт. Уже применённые миграции не редактируйте — добавляйте новые.

Локальные базы, WAL/SHM, `.env*` (кроме `.env.example`) и `public/uploads/` исключены из Git. Не размещайте секреты в `NEXT_PUBLIC_*`.

Статус реализации и известные ограничения находятся в TASKS.md и PROGRESS.md. Публикация в интернет не настроена.

## Вход владельца

Откройте `/ru/admin/login` (также доступны `/en/admin/login` и `/kk/admin/login`). До настройки секретного ключа форма входа недоступна.

1. Скопируйте `.env.example` в `.env.local`.
2. Задайте собственный случайный `BETTER_AUTH_SECRET` длиной не менее 32 символов, `DEID_OWNER_EMAIL`, `DEID_OWNER_PASSWORD` (12–128 символов) и `DEID_OWNER_NAME`. Не присылайте пароль в чат и не добавляйте `.env.local` в Git.
3. Выполните `npm run owner:create`. Команда создаёт базу и одного владельца; повторный запуск не перезаписывает учётные данные.
4. Удалите `DEID_OWNER_PASSWORD` из `.env.local` после успешного создания. `BETTER_AUTH_SECRET` оставьте стабильным для сессий.
5. Перезапустите `npm run dev` и войдите с указанными email и паролем.

Адрес браузера должен соответствовать `BETTER_AUTH_URL` (по умолчанию `http://127.0.0.1:3000`). Публичная регистрация отключена. Админ-панель пока содержит вход и выход; редактор публикаций будет добавлен отдельным этапом. Реальная учётная запись автоматически не создаётся.
